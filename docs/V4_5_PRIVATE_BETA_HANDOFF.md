# Parallax PixelForge v4.6 — Private Beta Operations Alpha

v4.6 is the trusted-tester handoff milestone on the road to v5.0 private beta.

## Purpose

This release turns the v4.4 Beta Lock Candidate into a practical private-beta handoff workflow:

- package a clear tester handoff batch
- onboard trusted testers without accounts, public posting, or live chat
- collect structured feedback receipts
- keep known issues visible
- track beta exit criteria honestly
- prevent false claims that v5.0 has shipped before human review

## New Systems

### Private Beta Operations Desk
Tracks tester batches, included artifacts, trust circle targets, and no-public-release handoff rules.

### Tester Onboarding Runbook
A short tester flow: open locally, pick the route, play ten minutes, optionally run an AI companion pass, submit feedback receipt, close out with known issue notes.

### Feedback Receipt Inbox
Structured feedback cards for clarity, bugs, tone, delight, accessibility, and rights issues. No private chat logs.

### Known Issue Triage
Critical/high/medium issue review before v5.0. Critical issues block private beta unless guarded or resolved.

### Beta Exit Criteria
Keeps v5.0 private beta in an honest amber state until required checks are green and human-reviewed.

### v5 Readiness Gate
A plain readiness gate, not a shipped claim.

## Boundary

v4.6 is still local-first. It does not enable public networking, public BBS posting, live relay hosting, or remote save access by default.
