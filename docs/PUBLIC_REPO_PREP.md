# Public Repo Prep Notes

PixelForge can move toward a public MIT repository, but the public cut should be deliberately scoped.

## Public-safe defaults

- Local-first only.
- No accounts required.
- No public BBS enabled by default.
- No live relay enabled by default.
- No free-text co-play chat.
- No hidden profiling.
- No autonomous external actions.
- No remote save overwrites.
- Rights metadata stays attached to packs and demo cartridges.

## Recommended public launch shape

- PixelForge Creator OS shell.
- Game Shelf and `Play Demo` route.
- World Builder / Pixel Studio / Writers Studio / Chiptune Studio as local creator tools.
- Journey to the Parallax Pyramid as the bundled proof cartridge.
- Private beta / BBS / relay / AI bench modules marked experimental and locked unless explicitly enabled.
