# v5.0 Private Beta

## Purpose

v5.0 is the first trusted-tester private beta package for Parallax PixelForge. It exists to get real people and AI companions through the core creator loop while preserving the project’s local-first, no-chat, rights-aware, consent-boundary design.

## Private beta scope

- Invite-only trusted tester flow
- Local-first studio boot and demo playtest
- No-chat co-play room simulation / safe relay planning
- Feedback cards and playtest receipts
- Cartridge shelf, release gate, and pack-review workflows
- AI companion playtest support with reviewable local memory only

## Not included

- No public launch
- No open social network
- No free-text multiplayer chat
- No automatic outreach to testers
- No hidden user profiling
- No remote save overwrites
- No unreviewed public asset distribution

## v5.0 promise

A tester should be able to unzip the package, open the studio, understand the first-run path, test the demo, file structured feedback, and see the safety/rights boundaries clearly.

## Next train

v5.1 should focus on beta feedback repair, UI simplification, and tester-discovered blockers before any broader release conversation.
