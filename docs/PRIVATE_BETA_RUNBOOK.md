# Private Beta Runbook

1. Confirm the tester is in a trusted circle.
2. Share the private beta packet manually.
3. Ask the tester to run local validation if comfortable.
4. Ask them to open `index.html` or run the local server.
5. Have them test the Creator OS loop: Shelf → World Builder → Playtest Theater → Release Gate.
6. Collect structured feedback cards only.
7. Record issues in the local issue/feedback workflow.
8. Close out with gratitude and no pressure.

No automatic outreach, public posting, or free-text co-play chat is part of this beta.
