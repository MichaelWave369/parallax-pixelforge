# PixelForge Sprite Studio v5.9

Sprite Studio is the built-in SNES-first pixel-art workstation for PixelForge.

## What it does

- Draw with pencil, eraser, bucket fill, eyedropper, line, and rectangle tools.
- Work at 16×16, 24×32, 32×32, 32×48, 64×64, or 96×96.
- Use PixelForge SNES house palettes or a custom color.
- Mirror frames horizontally/vertically, adjust zoom, and use local undo/redo.
- Seed a complete 23-frame SNES hero animation workspace with one click.
- Create, duplicate, label, and delete animation frames.
- Onion-skin previous/next frames and preview animation at 1–24 FPS.
- Export a horizontal PNG sprite sheet.
- Export a JSON animation map grouped by frame label.
- Attach the result to the project Sprite Gallery and export an Asset Forge attachment receipt containing the declared rights state and SHA-256.

## More Bounce baseline

The default Sprite Studio canvas is **32×48**, the PixelForge SNES hero target. Suggested labels are `idle`, `walk`, `run`, `bounce`, `interact`, `damage`, and `victory`.

## Evidence boundary

The editor can prove dimensions, frame structure, palette selection, file hashing, and declared rights state. It cannot prove that artwork is beautiful, original in a legal sense, or worthy of the PixelForge SNES gold-standard label. Those remain human review decisions.
