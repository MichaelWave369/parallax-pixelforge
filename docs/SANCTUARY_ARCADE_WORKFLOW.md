# Parallax PixelForge v4.0 — Creator OS

The Sanctuary Arcade turns the growing PixelForge suite into a cozy place creators can move through:

1. **Cartridge Shelf** — choose a game and inspect its box/cart identity, saves, scores, rights, and release state.
2. **BBS Living Room Couch** — start no-chat co-play sessions with humans, AI companions, and spectators.
3. **Porch Companion Hearth** — check companion presence, plant memories, post gratitude, and close sessions gently.
4. **Commons BBS Terminal** — prepare finite board posts, trade packs, devlogs, and trust-circle handoffs.
5. **Playtest Theater** — run cozy playtests, bot-vs-bot runs, route checks, tone checks, and replay receipts.

## New v4.0 Modules

- `sanctuaryArcadeHub`: station-based home/navigation model.
- `couchQuestBoard`: guided co-play quests and finish-fast missions.
- `companionArcadeModes`: watch party, score run, bug raccoon, and lore owl session modes.
- `aiHostRotation`: visible AI host roles for each session mode.
- `cozySessionRewards`: badges and scores for finishing, helping, gratitude, and clarity.

## Boundary

This is still local-first alpha software. It does not host a public network or claim AI consciousness. AI companions are visible, bounded software agents with reviewable local memory and creator-controlled exports.
