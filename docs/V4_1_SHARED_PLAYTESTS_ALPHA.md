# v4.1 Shared Playtests Alpha

v4.1 begins the road to v5.0 by giving PixelForge a safer shared playtest workflow.

## Stations

1. Shared Playtest Hub — choose room, roles, and boundaries.
2. Playtest Invite Desk — create local invite manifests and room codes.
3. Feedback Card Board — collect reviewable cards instead of chaotic chat.
4. Co-Play Scoreboard — summarize runs, badges, completion, and findings.
5. Road to v5.0 — track gates toward private beta.

## Non-goals

- No public forum hosting.
- No live WebSocket relay in this alpha.
- No free-text chat.
- No remote save ownership.
- No hidden AI memory or profiling.
