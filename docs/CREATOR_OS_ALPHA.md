# Parallax PixelForge v4.0 — Creator OS Alpha

v4.0 promotes PixelForge from a collection of creator stations into a cozy local-first **Creator OS** for building, testing, shelving, sharing, and evolving retro myth-games.

## New systems

- **Creator OS Dashboard** — one overview across Cartridge Shelf, World Builder Arcade, Sanctuary Arcade, Commons BBS, and Release Gate.
- **Cartridge Lifecycle** — tracks idea spark → world seed → route/questline → starter cartridge → AI scout → release gate → shelf/BBS → sequel hook.
- **AI Agent Orchestrator** — assigns local AI companion roles to route scouting, vibe checks, bug tests, lore continuity, and audio passes.
- **Experience Map** — navigation map for Shelf, World Builder, Porch Hearth, Playtest Theater, Commons BBS, and Release Gate.
- **Release Train** — milestone cars and gates for v4.x polish and future beta path.
- **System Codex** — local architecture, safety, and release notes for the Creator OS contract.

## Boundaries

- No free-text BBS chat is added.
- AI companions remain local software agents with reviewable, game-specific memory.
- No consciousness claims are made.
- Rights metadata stays attached to packs before sharing.
- v4.0 is still local-first; no live hosted service is created.
