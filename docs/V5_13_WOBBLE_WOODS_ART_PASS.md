# PixelForge v5.13 — Wobble Woods Art Pass

## Purpose

v5.13 converts Wobble Woods from a playable side-view layout with placeholder presentation into an original PixelForge SNES-style environment pack bound directly into the Legend runtime.

## New original art

- `wobble-woods-tiles.v0.1.png` — 16 native 16×16 tiles (256×16 sheet).
- `wobble-woods-layer-far.v0.1.png` — 672×180 far canopy/dusk layer.
- `wobble-woods-layer-mist.v0.1.png` — 672×180 transparent mist layer.
- `wobble-woods-layer-near.v0.1.png` — 672×180 near trees/trunks layer.
- `wobble-woods-layer-foreground.v0.1.png` — 672×180 foreground foliage layer.
- Reusable tile motifs include ground, platforms, far/near canopy, trunks, mist, bounce flora, ruins, Echo Gate, Bounce Rune, moss stone, glow mushroom, bramble and sparkle.

## Runtime binding

The Wobble runtime retains authored physics and game state:

- side-view camera follow;
- platform geometry;
- gravity and jumping;
- three bounce pads;
- Bounce Rune pickup;
- Echo Gate objective;
- return path to Bouncehome Grove;
- More Bounce's existing 23-frame 32×48 hero sheet.

The new environment pack is rendered in distinct depth layers so parallax remains runtime behavior rather than a single flattened screenshot.

It does not prove that the artwork has passed human visual-gold-standard review. That approval remains a separate human gate.
