## v4.0 Commons Rooms + Pack Exchange Notes

v4.0 expands the Infinite Commons bridge from a concept panel into a creator-community workflow:

- **Room Boards** keep each Commons room finite, curated, and focused on creation.
- **Pack Exchange** supports cartridge, asset, music, receipt, and jam-pack exchange manifests.
- **Share Ledger** records local sharing events and keeps rights metadata attached.
- **Trust Circles** define who a pack is meant for before it leaves the creator's machine.
- **Moderation Queue** keeps kindness-first, no-chat, no-vanity, and rights-first boundaries visible.

No public network, live LAN sync, or automatic encryption is performed in this alpha. These are local-first manifests and workflow panels.

## Creator OS

Use the Creator OS after the Cozy Home / Shelf flow when you want to make a new playable world quickly. Start by cycling the World Seed Forge, then weave a route, refresh region cards, compose a tiny questline, and export the World Bible when the creator accepts the canon.


## v4.0 Creator OS workflow

1. Choose or forge a world seed.
2. Preview the route map.
3. Build a starter cartridge kit.
4. Run Region QA and AI World Scout.
5. Refresh World Launch Checklist.
6. Export the launch artifacts before sharing.


## v4.0 Creator OS Quick Flow

1. Open **Creator OS Dashboard** and sync readiness.
2. Advance **Cartridge Lifecycle** until AI Scout / Theater is active.
3. Assign the next **AI Agent Orchestrator** task.
4. Check **Experience Map** to move between Shelf, World Builder, Porch, Theater, Commons, and Release Gate.
5. Use **Release Train** and **System Codex** before sharing a pack.
