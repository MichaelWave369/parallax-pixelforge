# PixelForge Open Source Community Wave

The public strategy is simple:

> Give people the forge for free. Give them a few lovable cartridges as examples. Let them make their own tiny worlds.

## Public repo shape

Recommended first public repo:

```text
parallax-pixelforge/
  app.js
  index.html
  styles.css
  data/
  docs/
  games/
    journey-to-parallax-pyramid/
  pocketgames/
    templates/
  scripts/
  tests/
```

## What is free/open

- PixelForge Studio core tools
- Project schema and validators
- Local-first cartridge format
- Example/demo cartridges
- Documentation and templates
- Community contribution flow

## What should stay gated until reviewed

- Public BBS or relay networking
- Free-text public chat
- Remote save sync
- Hidden profiling or background telemetry
- Unreviewed third-party assets
- Automated public publishing
- App-store production signing

## Community-created game flow

1. Creator forks PixelForge.
2. Creator starts from a cartridge template.
3. Creator fills out a PocketGame manifest if they want mobile-ready packaging.
4. Creator verifies all assets and text are original/license-safe.
5. Creator runs tests and validators.
6. Creator submits a PR or shares the game as an independent cartridge pack.
7. Maintainers review safety, rights, playability, and claim boundaries.

## Contribution standards for sample cartridges

A public sample cartridge should be:

- playable locally,
- understandable quickly,
- free of copyrighted franchises or unlicensed assets,
- non-exploitative,
- no hidden tracking,
- no accounts required,
- no gambling/loot-box design,
- clear about symbolic fiction vs factual claims,
- kind enough that the repo feels like a creative sanctuary.

## Why this can catch a wave

Most game tools either feel too technical or too huge. PixelForge can be different by focusing on:

- tiny games,
- cozy creator flow,
- retro cartridge energy,
- local-first safety,
- simple manifests,
- “play once and love it” design.

The repo should make people think: **I could actually finish one of these.**
