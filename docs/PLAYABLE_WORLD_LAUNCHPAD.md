# Parallax PixelForge v4.0 — Creator OS Alpha

v4.0 turns the World Builder Arcade into a tighter launch flow: world seed → route map → region QA → starter cartridge → AI scout report → launch checklist.

## New systems

- **Starter Cartridge Builder** — bundles an active seed, route, questline, and scene set into a finishable cartridge plan.
- **Route Map Preview** — shows scene order, gate requirements, emotional beats, and route risks.
- **Region QA Pass** — tracks visual/story/audio/gate checks per region with AI companion owners.
- **World Launch Checklist** — preflight gate for validation, rights metadata, no-chat boundaries, QA, and scout receipts.
- **AI World Scout** — local, reviewable AI route reports for playable world QA.

## Boundary

AI World Scout memories are local, game-specific, and reviewable. They must not be used for hidden profiling or consciousness claims.
