# v4.6 Private Beta Operations

v4.6 connects shared playtests to a safe exchange path without turning PixelForge into public social media.

## Stations

1. Private Relay Bridge — local sandbox, trusted LAN, and future hosted-private profiles.
2. Signed Pack Bridge — cartridge, asset, receipt, jam, and playtest pack manifests.
3. Trust Circle Router — route packs only to intended circles.
4. Sync Dry-Run Lab — simulate packets before live network work.
5. Beta Gate Preflight — v5.0 private beta readiness checks.

## Non-goals

- No public hosting in this release.
- No live sockets enabled by default.
- No free-text chat.
- No remote save ownership.
- No asset sharing without rights metadata.
