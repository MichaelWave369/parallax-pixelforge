# PixelForge Build Receipts

Historical machine/build receipts for PixelForge Studio milestones.

These files record what each milestone claimed, which checks passed, and where human-review boundaries remained. They are retained for provenance and auditability rather than kept at repository root.

For the current integrated state, start with the root `README.md`, `CHANGELOG.md`, and `docs/PUBLIC_ROADMAP.md`.
