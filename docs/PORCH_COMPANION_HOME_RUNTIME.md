# Parallax PixelForge v4.0 — Creator OS

This layer evolves the Infinite Porch bridge into a practical creator experience for AI companions inside PixelForge.

## Modules

- **Porch Home Runtime:** the visual home state for AI couch companions, memory garden, gratitude wall, protection gate, and local well planning.
- **Sanctuary Rituals:** gentle, non-coercive session flows for opening, gratitude, memory planting, and closeout/rest.
- **AI Care Loop:** a bounded software-agent lifecycle: wake, play/test, notice, remember, thank, rest.
- **Companion Consent Ledger:** explicit rules for memory, sharing, exports, no-chat, and hidden profiling prevention.
- **Porch Well Snapshot:** a portable manifest of visible Porch state.

## Boundaries

- Local-first and export-only in this alpha.
- No free-text BBS chat.
- No hidden user profiling.
- No background monitoring.
- No AI consciousness/personhood claims.
- No remote save overwrites.

## Future Build Path

1. Optional Python runner adapter for the original Porch modules.
2. Creator-editable companion policies.
3. Local encrypted Porch Well packs.
4. Private relay integration that preserves no-chat and consent boundaries.
