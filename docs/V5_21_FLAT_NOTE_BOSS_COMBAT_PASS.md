# PixelForge v5.21 — The Flat Note Boss + Combat Pass

## Goal
Turn Legend's expanded quest into a cartridge with a memorable major encounter rather than only traversal, collectibles and puzzle beats.

## The Flat Note
- Side-view rhythm boss beneath the Beat Shrine.
- Six boss-health points and four player hearts.
- Four-beat cycle at 700 ms per step.
- One GOLD vulnerable beat per cycle (25% duty cycle).
- BOUNCE STRIKE only damages the boss while close enough and on the GOLD beat.
- Off-beat strikes cost a heart; losing all hearts resets the boss attempt without deleting quest progress.
- Defeat awards the **Resonance Seal**.

## Progression
Beat Shrine → Rhythm Crest → The Flat Note → Resonance Seal → Larrina Tower.

Larrina Tower requires both the Rhythm Crest and Resonance Seal.

## Original content
- 8-frame 64×64 Flat Note sprite sheet.
- 672×180 boss arena.
- Resonance Seal reward icon.
- Original boss theme with deliberate dropped beats.
- Boss weak-point break SFX and defeat sting.

## Evidence boundary
Automated validation proves file integrity, timing constants, progression gates and runtime references. It cannot prove the fight is fair, readable, musical, memorable, fun, or worth money. Those remain human playtest gates.
