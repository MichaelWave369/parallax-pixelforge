# Parallax PixelForge v4.7 — Private Beta Operations Alpha

v4.7 is the beta-operations milestone on the road to v5.0 private beta.

## Purpose

v4.5 created the tester handoff. v4.7 adds the operating layer for running that handoff safely:

- track beta sessions
- organize tester cohorts without turning them into rankings
- digest feedback into reviewable patterns
- monitor issue trends
- assemble a release-candidate packet
- keep the v5 go/no-go decision honest and human-approved

## New Systems

### Beta Operations Console
Daily loop for collecting receipts, digesting feedback, updating issues, refreshing RC artifacts, and closing sessions with gratitude.

### Beta Session Ledger
Structured session records for human, AI-assisted, and no-chat co-play passes. No hidden profiling or chat logs.

### Tester Cohort Dashboard
Small trusted cohorts for private playtesters, creator collaborators, and local AI bench passes.

### Feedback Digest
Summarizes structured feedback receipts into top patterns and recommended actions without inferring private tester traits.

### Issue Trend Board
Tracks recurring issues and keeps critical trends blocking v5 until resolved or explicitly guarded.

### Release Candidate Assembler
Prepares the v5 private beta RC seed packet while clearly stating that a candidate package is not a public release.

### v5 Go/No-Go Review
Keeps the decision on hold until a human release owner approves.

## Boundary

v4.7 does not enable public networking, public BBS posting, hosted multiplayer, free-text chat, or remote save control. It is a local-first operations alpha.
