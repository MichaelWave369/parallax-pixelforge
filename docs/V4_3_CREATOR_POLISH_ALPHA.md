# Parallax PixelForge v4.6 — Private Beta Operations

v4.6 is the first road-to-v5 polish release. The goal is not feature sprawl; the goal is to make the Creator OS easier, warmer, clearer, and safer for trusted private beta playtests.

## Core additions

- Beta Lock Dashboard: first-run clarity, panel simplification, visual readability, and microcopy passes.
- First-Run Tutorial Flow: a ten-minute path from shelf → world builder → playtest theater → release gate → safe pack export.
- UX Polish Board: tracks friction, export confusion, panel overload, and success-moment improvements.
- Accessibility Pass: contrast, keyboard flow, no audio-only dependency, motion comfort, and plain-language checks.
- Beta Readiness Scorecard: overall private beta readiness across core loop, UX, accessibility, safety, and playtests.
- v5 Polish Queue: remaining tasks before the v5 private beta gate can turn green.

## Boundary

v4.6 keeps PixelForge local-first and no-chat by default. It does not enable hosted multiplayer or public sharing. It prepares the creator experience for safer trusted playtests.
