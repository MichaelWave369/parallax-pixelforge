# PixelForge v5.11 — Runtime Composer

## Goal

Close the loop between asset authoring and a playable game scene. v5.11 lets a creator bind live Sprite Studio and Tile Studio work into an immediately controllable local SNES-style scene.

## Candidate capabilities

- camera-follow viewport
- keyboard movement
- normalized diagonal speed
- Map Composer collision blocking
- live Sprite Studio idle/walk frame selection
- live Tile Studio ground/decor rendering
- collision and tile-grid debug overlays
- explicit semantic-preview boundary when final art is missing
- portable runtime-scene JSON export
- additive project persistence and attached runtime-scene registry

## Non-claims

This candidate does not claim final Legend art, combat, physics, NPC AI, or a production cartridge runtime. It proves the authoring-data-to-playable-scene bridge.
