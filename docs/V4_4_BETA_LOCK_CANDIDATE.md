# Parallax PixelForge v4.6 — Private Beta Operations

v4.6 is the road-to-v5 freeze release. The goal is to stop feature sprawl, lock the private-beta surface, and prepare a trusted tester handoff.

## New systems

- Beta Lock Dashboard: visible gates for schema freeze, core loop, safety, and tester handoff.
- Schema Freeze Ledger: additive-only compatibility policy for v5.0 private beta.
- Release Blocker Board: critical/high/medium blocker triage before private beta.
- Tester Handoff Packet: concise instructions and allowed exports for trusted testers.
- Regression Test Matrix: smoke checks, core-loop checks, and safety-boundary checks.
- v5 Private Beta Candidate Manifest: readiness state without claiming v5 has shipped.

## Boundary

This release still does not enable public hosting, public networking, public social feeds, or automatic external sharing. v4.6 is a lock-and-handoff candidate for private beta preparation.
