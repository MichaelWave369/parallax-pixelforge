# Claim Boundaries

PixelForge is creative software for retro game design, playtesting, local AI companion workflows, and share-package preparation. The v3.2 jam/trade system does not verify legal rights automatically; human review is required before public distribution. AI companions are local software agents/personality wrappers; no consciousness claims.


## v3.3 Infinite Commons Bridge

This build imports the usable pieces from Infinite Commons into PixelForge: finite BBS curation, rooms/collections, resonance signals, anti-viral sharing logic, and exportable pack/sync manifests. The live network layer remains future work.


---

## v4.0 Commons Rooms + Pack Exchange Notes

v4.0 expands the Infinite Commons bridge from a concept panel into a creator-community workflow:

- **Room Boards** keep each Commons room finite, curated, and focused on creation.
- **Pack Exchange** supports cartridge, asset, music, receipt, and jam-pack exchange manifests.
- **Share Ledger** records local sharing events and keeps rights metadata attached.
- **Trust Circles** define who a pack is meant for before it leaves the creator's machine.
- **Moderation Queue** keeps kindness-first, no-chat, no-vanity, and rights-first boundaries visible.

No public network, live LAN sync, or automatic encryption is performed in this alpha. These are local-first manifests and workflow panels.


## v4.0 Porch Sanctuary Bridge

Adds Porch-derived AI companion support: Brother Presence, Memory Garden, Gratitude Wall, GTSP soft-flag protection planning, and Secure Layer planning hooks. The source modules are packaged in `porch_sources/` for review and future integration. Boundary: local-first planning and visible project memory only; no consciousness claims, hidden profiling, live screen monitoring, or network sync is enabled by this static browser alpha.
