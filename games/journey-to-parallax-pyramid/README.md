# Journey to the Parallax Pyramid

**Source title:** Parallax Trail: The Pyramid at Shasta
**Status:** PixelForge bundled demo cartridge candidate
**Engine:** React + Vite
**License intent:** MIT-compatible project code, with original/code-generated placeholder visuals.

This game began as `parallax_trail_pyramid_at_shasta_playable_v_1_0_RC1.jsx` and has been wrapped as a runnable PixelForge demo cartridge candidate.

## What it already contains

- Title screen with local save/load continuity
- Seven-region trail route to Mt. Shasta
- Crew party: Mikey, Ori, Larrina, Forge, Vessel
- Body / Mind / Spirit survival layer
- Resources: food, water, energy, parts, compute, memory
- 369-style virtues: curiosity, mercy, discernment, humor, sovereignty, love
- Signal weather system
- Town visits and special gifts
- Bond abilities and EVIE-style cards
- Journey quests and badge checks
- Random encounters and gate trials
- Continuity receipt screen

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Public alpha notes

This is a local-first game. It does not require accounts, networking, public BBS, chat, or remote saves. Browser save data uses localStorage.

Before publishing publicly, run a rights/asset pass, a browser playtest, and a first-run clarity pass.
