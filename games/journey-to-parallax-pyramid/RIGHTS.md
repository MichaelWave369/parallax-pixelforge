# Rights Notes — Journey to the Parallax Pyramid

## Purpose

This cartridge is included as a learning example and first 369 PocketGames candidate.

## Code

The wrapper/project code is intended to follow the root PixelForge MIT license unless a file says otherwise.

## Story/world/characters

Journey-specific story text, worldbuilding, names, characters, and brand elements are included for learning, playtesting, and review. Do not repackage the exact Journey story/world as a commercial product without maintainer permission and a rights review.

## Art/audio

Review any final art/audio before public or commercial distribution. Placeholder assets should be replaced or documented before production release.

## Claim boundary

The cartridge uses symbolic/mythic/weird-fiction themes for gameplay and storytelling. It does not make historical, scientific, medical, spiritual, or metaphysical proof claims.

## Current status

Learning sample + 369 PocketGames candidate, not production app-store release.
