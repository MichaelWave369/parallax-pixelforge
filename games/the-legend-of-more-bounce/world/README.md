# Legend World Authoring Seeds

## Bouncehome Grove

`bouncehome-grove.tile-map.v5.10.json` is the first v5.10 Map Composer level seed. It defines a 24×16 SNES-scene layout with a west-to-east adventure path, forest banks, optional pond, old ruin landmark, flower/rune decor, explicit collision, and the Echo Gate approach.

`bouncehome-grove.tile-studio-seed.v5.10.json` is a Tile Studio-compatible working state with the same layout and eight named tile roles. **All 16×16 pixel arrays are intentionally blank.** That keeps the level design usable while preserving the v5.8/v5.10 truth boundary: final SNES art remains `awaiting-art` until it is actually drawn or attached and reviewed.

Suggested art order:

1. Grass
2. Golden Path
3. Tree Edge variants
4. Moon Pond variants
5. Bounce Flowers
6. Old Stone variants
7. Echo Gate
8. Rune Accent
