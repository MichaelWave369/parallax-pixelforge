# Legend Runtime Seeds

`bouncehome-grove.runtime-scene.v5.11.json` is the first Runtime Composer scene packet for Legend of More Bounce. It binds the existing 24×16 Bouncehome Grove layout/collision data to a More Bounce hero slot, camera-follow settings, spawn, and the future Echo Gate transition.

The scene is structurally playable, but final hero and environment art remain explicitly `awaiting-art`. Semantic preview rendering must not be treated as production art.
