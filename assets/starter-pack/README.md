# PixelForge Starter Asset Pack

A deliberately tiny set of original vector assets for first-time PixelForge creators.

Included:

- `cartridge.svg` — generic retro cartridge icon.
- `spark.svg` — generic creative spark icon.

These are teaching assets, not a style mandate. Replace them as soon as your cartridge develops its own identity.
