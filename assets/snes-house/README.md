# PixelForge SNES House Foundation v1

This is the reusable v5.8 asset contract for PixelForge's default 16-bit lane. It separates **art direction and asset structure** from **finished art**.

## What lives here

- reusable palette definitions,
- asset-slot vocabulary,
- sprite/tile/frame targets,
- rights boundaries,
- profile templates.

## What does not live here yet

Finished More Bounce/Larrina sprite sheets or production environment art. Those slots remain explicitly `awaiting-art` until real original assets are supplied and reviewed.
