# PixelForge SNES House Foundation — Rights Notes

The JSON contracts, palette definitions, and documentation in this folder are original PixelForge project material.

This folder **does not contain third-party SNES/Nintendo art, extracted ROM assets, copied sprites, or franchise tilesets**. Future image/audio files added to a cartridge must carry their own source and rights status.

The phrase "SNES-style" describes a technical/presentation era target; it is not a claim of affiliation with Nintendo.
