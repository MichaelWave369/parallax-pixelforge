# PixelForge Community Catalog Schema Notes — v5.5

Top-level schema: `pixelforge.community-catalog.v5.5`.

Each cartridge entry includes identity, version/status, creator/studio, description, modes/tags, featured-learning metadata, local paths, review badges, review result, and summarized playtest counts/averages.

The catalog intentionally contains no account identifiers, device identifiers, advertising IDs, hidden telemetry, or behavioral-profile fields.
