# Local Playtest Receipts

This directory stores explicit, portable playtest receipts for the v5.5 Community Cartridge Shelf.

Two receipt kinds are supported:

- `human-playtest` — optional 1–5 ratings and notes explicitly entered by a tester.
- `automated-browser` — deterministic browser-flow evidence with no subjective fun score.

PixelForge does not infer hidden preferences, construct behavioral profiles, or upload these receipts anywhere by default.
